Use a generated app password

Follow the steps below to generate an App Password.

Enable 2-Step Verification & generate an App Password

  1. Go to your Google Account → Security settings
  2. Under "How you sign in to Google", enable 2-Step Verification
  3. Return to Security → scroll down to App Passwords
  4. For App name enter Other (Custom name) → click Generate
  5. Copy the 16-character password shown — you'll enter it in the next step
Watch tutorial / view guide

Enable SMTP Auth & generate an App Password

  1. Sign in to Microsoft 365 Admin Center or your account settings
  2. Go to Security → Multi-factor authentication and enable it
  3. Go to My Account → Security info → Add sign-in method → choose App password
  4. Give it a name and click Next — copy the generated password
  5. Make sure SMTP AUTH is enabled for your mailbox in the Admin Center
Watch tutorial / view guide
