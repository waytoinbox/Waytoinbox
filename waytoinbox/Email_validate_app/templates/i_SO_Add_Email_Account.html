Use a generated app password

Follow the steps below to generate an App Password.

Enable 2-Step Verification & generate an App Password

  1. Go to your Google Account → Security settings
  2. Enable 2-Step Verification
  3. Return to Security → App Passwords
  4. Enter a name (e.g. WayToInbox) → click Generate
  5. Copy the 16-character password shown
View Google guide

Enable SMTP Auth & generate an App Password

  1. Sign in to your Microsoft account settings
  2. Enable Multi-factor authentication
  3. Go to Security info → Add sign-in method → choose App password
  4. Give it a name and copy the generated password
  5. Ensure SMTP AUTH is enabled for your mailbox
View Microsoft guide
