 1. BULK EMAIL VERIFY WORKFLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

User uploads CSV file on /services/
        │
        ▼
[View] Validate file
  - Size ≤ 50 MB?
  - Extension .csv / .xlsx / .json / .txt?
        │
        ▼
Save file → private_uploads/
        │
        ▼
Create ListFiles record (job_status = "Pending")
Create dynamic MySQL table → WIN_<id>_YYYY_MM_DD
        │
        ▼
Dispatch validate_email_list_task → Celery queue
Return "Job started" to user
        │
        ▼
[Celery] validate_email_list_task
  - Set job_status = "Processing", started_at = now
  - Read CSV in chunks of 500 rows
        │
        ▼
Split into N chunks → dispatch all validate_chunk_task
(all chunks run in PARALLEL)
        │
     ┌──┴───────────────────────────┐
     ▼                              ▼
validate_chunk_task #1    validate_chunk_task #N
50 threads per chunk      50 threads per chunk

Each email goes through:
  1. Format check
  2. Role-based check      (admin@, info@ → Others)
  3. Disposable check      (mailinator, etc. → Risky)
  4. Blacklisted check     (blocked domains → Others)
  5. Suspicious check      (test, fake, noreply → Risky)
  6. MX record lookup      (cached in Redis 1 hour)
  7. Catch-all SMTP probe  (random address test → Risky)
  8. SMTP handshake        (250=Valid, 550=Invalid, 450=Risky)

Returns: { email → Valid / Invalid / Risky / Others }
     └──────────┬───────────────────┘
                │
                ▼
All chunks done → chord callback fires
                │
                ▼
[Celery] finalize_validation_task
  - Merge all results
  - Write results back to CSV file
  - Bulk upsert → AllEmails table
  - Update ListFiles:
      valid_count, invalid_count, total_count
      job_status = "Complete", completed_at = now
  - Send in-app notification
  - Send email to user (if enabled)
        │
        ▼
User sees job card → status = Complete
        │
        ▼
User clicks Download
  - Check VC credits ≥ (valid + invalid count)
  - Deduct VC credits (atomic, locked)
  - Serve filtered CSV (All / Valid / Invalid)

  draft      →  Created, not sent yet
  scheduled  →  Waiting for send time
